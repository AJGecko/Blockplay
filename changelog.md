## [0.2.0] - Physics Update

> It still in development and there will more updates in the future.

> Note: The program currently needs to be started manually using Python or you use the web version.

You can download the latest version of the game from the releases page:
[`V.0.2.0`](https://github.com/AJGecko/Blockplay/releases)

Web Version: [Blockplay Web Version](https://blockplay-game.vercel.app/)

### New Features
- New physics engine system (more realistic and fun)
- Platforms are now solid from the sides and bottom
- Lazy camera option added (can be enabled in settings, makes the camera follow the player with a delay)
- Fixed the mouse scroll wheel not working in the settings menu
